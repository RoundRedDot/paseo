## Literal values versus private generated credentials

- **SYNTHETIC:** `ephemeral-local-enrollment` and its `Bearer` form at final harness lines 53/141. This is a hardcoded enrollment token accepted only by the temporary loopback Hub counterpart. It was chosen by the harness, not generated by the daemon, and is not a real user/device/provider credential. The public harness may contain this explicitly synthetic literal.
- **REDACTION MARKER:** the transcript value `credential: "REDACTED"` is a marker, not a secret.
- **PRIVATE, NOT COPIED:** the daemon-generated random Hub `credential.secret`, its actual verifier, daemon private keys, and persisted `state/` files. They are not included in this manifest or public artifacts. Runtime verification used them in memory; private state was removed by cleanup. No private secret is reconstructed or copied for this correction.
- Local `qa-*` client IDs and generated workspace/server/request/subscription IDs identify temporary test data; they are not authentication credentials.

This correction changes only the report, public summary and manifests. Protected harness/config/raw logs/results retain their previous SHA256 values; neither runtime case is rerun.
